# Contributing to ACID

## Rules

1. Truth over appearance. Never fabricate results.
2. Evidence over claim. Every assertion needs executed evidence.
3. Execution over explanation. Code must run.
4. No hidden intelligence in substrate.
5. Independent verification. Discovery cannot certify itself.
6. Reproducibility from seed + config.
7. Correct failure over fabricated success.

## Epistemic Discipline

Every claim classified: FACT | DERIVED | INFERRED | EXPERIMENTAL_RESULT | UNVERIFIED | SPECULATIVE | UNKNOWN
