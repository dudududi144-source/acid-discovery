Overview

ACID is a system that discovers, verifies, distills, and transfers computational mechanisms through evolutionary search on a minimal substrate.

18 Primitives 5 Verification Tests 21 Tasks 23 Modules Multi-User SSE Streaming

Usage

Python Client

from acid import ACIDClient

client = ACIDClient()
result = client.solve(
    problem="Sum of 3 integers",
    inputs=[1, 2, 3],
    expected=[6]
)
print(result)

Batch Processing

from acid import BatchRunner

runner = BatchRunner()
results = runner.run_task_library(max_difficulty=3)
print(runner.get_summary())

Run Tests

from acid import run_all_tests

results = run_all_tests()
